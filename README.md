# Dawa's Portfolio

A premium, animated, dark-themed portfolio built with Next.js, Tailwind CSS, and Framer Motion.

## Features

- **Dynamic Hero Section**: Gradient text, animated entrance, and status indicator.
- **Interactive Timeline**: A visual journey of your career from hacking to AI engineering.
- **Skill Matrix**: Categorized grid of technical expertise.
- **Project Showcase**: 3D-styled cards highlighting key projects.
- **Ventures Section**: showcasing your brands and startups.
- **Responsive Design**: Mobile-friendly navigation and layout.

## Tech Stack

- **Framework**: Next.js 14+ (App Router)
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Language**: TypeScript

## Getting Started

1.  Navigate into the project directory:

    ```bash
    cd portfolio-app
    ```

2.  Install dependencies (if not already done):

    ```bash
    npm install
    ```

3.  Run the development server:

    ```bash
    npm run dev
    ```

4.  Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Customization

- Edit `src/lib/data.ts` to update your biography, projects, skills, or social links.
- Modify `src/app/globals.css` to change the color scheme.
